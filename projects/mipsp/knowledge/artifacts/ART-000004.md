# Matriz de Trazabilidad Normativa

Modelo para conservar la relación entre la fuente normativa y los elementos pedagógicos derivados.

Cadena: `Fuente → Artículo / disposición → Obligación → Competencia → Tema → Evidencia → Evaluación → Curso`.

Cada elemento pedagógico relevante debe poder regresar a su fuente de origen; la matriz facilita la auditoría y evita perder la procedencia durante la descomposición curricular.
