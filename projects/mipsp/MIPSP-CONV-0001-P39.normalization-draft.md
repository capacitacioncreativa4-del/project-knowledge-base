# Borrador de normalización P39

## 1. Propósito del modelo

P39 propone un Modelo de Madurez Competencial para Seguridad Privada (MMC-SP) como componente de un Sistema Integral de Gestión de Competencias. El modelo busca distinguir etapas de desarrollo profesional y complementar los requisitos mínimos de capacitación, actualización y evidencia de competencia.

Sus objetivos son establecer una progresión objetiva, definir requisitos de promoción y especialización, orientar funciones de mayor responsabilidad, identificar necesidades formativas, apoyar la evaluación del desempeño y facilitar certificación y recertificación.

## 2. Niveles de madurez

La escala propuesta contiene seis niveles:

1. Aspirante: formación inicial y supervisión constante.
2. Operador Básico: tareas rutinarias conforme a consignas.
3. Operador Competente: resolución autónoma de incidencias frecuentes dentro de sus atribuciones.
4. Operador Avanzado: coordinación de actividades y apoyo a personal nuevo.
5. Supervisor Operativo: dirección de equipos, evaluación y gestión de riesgos.
6. Instructor o Especialista: diseño, impartición y evaluación de capacitación, además de mejora del sistema.

La escala se registra como propuesta de progresión y no como clasificación laboral o institucional aprobada.

## 3. Dimensiones de evaluación

Cada nivel se valoraría mediante ocho dimensiones:

- conocimiento normativo;
- competencia técnica;
- gestión del riesgo;
- toma de decisiones;
- comunicación;
- liderazgo, según el nivel;
- conducta profesional; y
- mejora continua.

Estas dimensiones cubren conocimiento jurídico, ejecución, riesgos, decisiones, información, coordinación, legalidad, ética, disciplina, integridad y optimización de procesos.

## 4. Rúbrica de madurez

La fuente propone calificar cada dimensión de 1 a 5: inicial, en desarrollo, competente, consolidado y referente institucional. Un promedio ponderado determinaría el nivel alcanzado.

La ponderación, los umbrales, la evidencia mínima y las reglas para resolver resultados dispares quedan pendientes de diseño y validación.

## 5. Requisitos para promoción

La promoción no dependería sólo de antigüedad. Debería considerar cumplimiento del plan formativo, evaluaciones teóricas y prácticas, desempeño observado, historial disciplinario, participación en simulaciones, indicadores operativos, evaluación del supervisor y evidencia documental de competencias.

Estos criterios se registran como propuesta metodológica y no como política de recursos humanos vigente.

## 6. Relación con el currículo

El modelo vincula los niveles con tipos de formación: inducción y formación básica; consolidación operativa; resolución de incidencias y gestión del riesgo; especialización y tutoría; supervisión y liderazgo; y diseño instruccional, evaluación y mejora continua.

## 7. Integración con el sistema de profesionalización

La fuente relaciona el MMC-SP con el IARF para requisitos normativos, el CMC para competencias, los PNO para procesos, los cursos para desarrollo, los instrumentos para evaluación, los KPI para desempeño operativo y el IRF para priorizar formación según riesgo.

El MMC-SP determinaría el grado de desarrollo profesional alcanzado, sujeto a una arquitectura de datos y reglas de trazabilidad aún no definidas.

## 8. Mapa de Competencias Operativas

P39 propone un Mapa de Competencias Operativas que muestre relaciones entre procesos, competencias y cursos. Los dominios ejemplificados son prestación del servicio, control de accesos, vigilancia preventiva, comunicación operativa y atención a emergencias, con subcomponentes de identificación, registros, recorridos, observación, reportes, escalamiento, evacuación y coordinación.

El mapa se plantea como columna vertebral para visualizar conexiones entre requisitos legales, competencias, cursos, procedimientos y evaluaciones.

## 9. Estructura editorial propuesta

La colección se proyecta en seis tomos: marco jurídico, IARF, CMC, programas y diseño instruccional, evaluación de competencias, y gestión, indicadores, auditoría y mejora continua. Se añade un volumen de apoyo para instructores y recursos didácticos.

La modularidad para empresas, instructores y responsables de capacitación se plantea junto con integración y trazabilidad completa.

## 10. Límites de esta normalización

- No se materializa el MMC-SP como política, estándar o clasificación institucional.
- No se crean niveles, competencias, mapas, KPI ni reglas de promoción como IDs institucionales.
- No se valida la relación entre madurez, certificación, recertificación o funciones laborales.
- No se definen ponderaciones, umbrales ni evidencias mínimas.
- No se crean IDs institucionales nuevos.
